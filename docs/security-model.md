# Security model

This model documents the lab's trust boundaries and its limits; it does not
certify production security. Gate 1 and Gate 2 passed on a single local profile
(2026-10-16), the `instance-down` and `ssh` drills passed, and the CPU drill
failed closed as `cpu-bounded`; the metrics bind is source-restricted to
Minikube by the host firewall and the negative-origin route test passes. The
timelines and audits stay private under `.local/evidence/`. Independent
reproduction on another machine was not performed, and the firewall rule is
operator-owned host configuration that must be persisted across reboots.

## Trust boundaries

- Workstation/controller (private): holds everything generated by `scripts/init.sh` — Ed25519
  key pair, Vault passphrase, encrypted Vault, `.local/` Grafana credential. Never versioned,
  never printed, never copied into build contexts or documentation.
- Compose lab (`ansible/`): build contexts are the `ansible/` directory, bounded by
  `ansible/.dockerignore` (the repository-root `.dockerignore` does not apply there); Dockerfiles
  copy explicit paths only, never the whole context. `app`/`db` are disposable teaching nodes;
  `control-node` mounts playbooks read-only.
- Kubernetes (`hybrid-infra-observability`, dedicated Minikube profile/context): Prometheus,
  Grafana and Alertmanager are ClusterIP-only; operator access is loopback-only port-forward.
  Grafana serves the provisioned dashboard and anonymous Viewer to that loopback UI; the
  admin credential remains for editing.
- Metrics route: one bridge bind (`HIO_METRICS_BIND`), never all-interface.
  `scripts/firewall.sh apply` restricts the published ports to the Minikube
  subnet on the proxy (INPUT) and DNAT (DOCKER-USER) paths, and
  `make route-check` proves no all-interface listener, a reachable Minikube
  node and blocked foreign Docker-network and LAN origins. Persist the
  firewall rules across reboots before relying on them.
- Alert path: the blackhole receiver demonstrates receipt through the Alertmanager API only —
  no external delivery is promised, and Alertmanager is intended to be stateless.

## Secrets (synthetic only)

Everything under `ansible/keys/`, `**/.vault_pass`, `**/vars/vault.yml` and `.local/` is generated
locally, ignored by git and excluded from build contexts. Contents are synthetic fixtures; the
Grafana admin password/Secret is generated per environment, not per invocation, so idempotent
re-runs never rotate it and rotation requires an explicit procedure. No rotation and no
existing-database password change is promised yet.

## Sudo exception

Unrestricted automation sudo on the lab nodes is an explicit lab exception, not hardening success.
Privilege separation on the teaching nodes is out of scope for wave 1.
