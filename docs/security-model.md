## Trust boundaries

- Workstation/controller (private): holds everything generated by `scripts/init.sh` — Ed25519
  key pair, Vault passphrase, encrypted Vault, `.local/` Grafana credential. Never versioned,
  never printed, never copied into build contexts or documentation.
- Compose lab (`ansible/`): build contexts are the `ansible/` directory, bounded by
  `ansible/.dockerignore` (the repository-root `.dockerignore` does not apply there); Dockerfiles
  copy explicit paths only, never the whole context. `app`/`db` are disposable teaching nodes;
  `control-node` mounts playbooks read-only.
- Kubernetes (`hybrid-infra-observability`, dedicated Minikube profile/context): Prometheus,
  Grafana and Alertmanager are ClusterIP-only; operator access is loopback-only port-forward.
- Metrics route: one bridge bind (`HIO_METRICS_BIND`), never all-interface.
  Gate 2 exercised the Docker-to-Minikube route, and the 2026-10-16
  negative-origin test now passes with the host firewall restricted to
  Minikube sources: no all-interface listener (the LAN address refuses),
  foreign Docker networks time out and the Minikube node keeps reaching the
  bind; private evidence in `.local/evidence/route-negative-20261016*.json`.
  Persist the firewall rule across reboots before relying on it.
- Alert path: the blackhole receiver demonstrates receipt through the Alertmanager API only —
  no external delivery is promised, and Alertmanager is intended to be stateless.

## Secrets (synthetic only)

Everything under `ansible/keys/`, `**/.vault_pass`, `**/vars/vault.yml` and `.local/` is generated
locally, ignored by git and excluded from build contexts. Contents are synthetic fixtures; the
Grafana admin password/Secret is generated per environment, not per invocation (checklist item 10).
No rotation and no existing-database password change is promised yet.

## Sudo exception

Unrestricted automation sudo on the lab nodes is an explicit lab exception, not hardening success.
Privilege separation on the teaching nodes is out of scope for wave 1.
